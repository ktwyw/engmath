# Notebook course

Twenty-one notebooks, each built around an original engineering problem. Every notebook

- states **what you will learn**, the **prerequisites** and the expected **time**;
- solves an engineering problem with the library, compares with SciPy and studies the errors;
- opens up the method in an **"Inside the algorithm"** section: the algorithm written out in a few
  lines of plain Python, checked against the library (and `show_source(...)` displays the library code);
- ends with exercises, including one **"Implement it yourself"** task.

## Running the notebooks

Read them on GitHub (all outputs and figures are included), run them locally with
`pip install -e ".[notebooks]"` and `jupyter lab`, or open them in Google Colab - the first cell installs
`engmath` automatically.

## Editing the notebooks

The notebooks are generated by `build_notebooks.py` (the single source of truth) and executed so that
GitHub shows all results:

```bash
python notebooks/build_notebooks.py            # regenerate and execute all notebooks
python notebooks/build_notebooks.py --no-run   # regenerate without executing
```

Edit `build_notebooks.py`, not the `.ipynb` files. Students can of course edit and run their own
copies freely.
